# Хлебничная

Одностраничный сайт в существующем Laravel-приложении. Маршруты: `routes/web.hleb.php`; домены `hleb.local`, `хлебничная.рф`, `xn--80ablnmob2dxa6f.xn--p1ai`. Кириллический домен и его IDNA-форма обслуживают одну страницу. CSS и JS независимы от общей сборки и других сайтов.

## Локальный запуск

Локальные hosts уже содержат `127.0.0.1 hleb.local`. В соседнем проекте `2508caddy_local/caddy/dev.Caddyfile` добавлен hleb.local к группе Laravel и отдельный HTTP-вход для предпросмотра. HTTPS использует локальный сертификат Caddy.

```sh
docker exec 2309livewire php artisan migrate --path=database/migrations/2026_10_29_100000_create_hleb_requests_table.php
docker exec 2309livewire php artisan test --compact tests/Feature/Hleb
```

## Заказы и франшиза

Корзина хранится в браузере; заявки сохраняются в `hleb_requests`. Цена рассчитывается на сервере; клиентская сумма игнорируется. Контакты шифруются ключом приложения, нужен резервный APP_KEY. Формы защищены CSRF, проверкой полей, согласием, ловушкой для ботов и ограничением частоты. Оплата онлайн и автоматические уведомления не подключены. Успешная форма означает сохранение заявки, а не подтверждение/оплату заказа.

Доступ сотрудника к заявкам — через серверную команду (публичного списка контактов нет):

```sh
docker exec 2309livewire php artisan hleb:requests
docker exec 2309livewire php artisan hleb:requests --id=1
```

Список не выводит контакты. Подробный просмотр раскрывает их только оператору с доступом к серверу. До приёма реальных заявок назначить ответственного за проверку списка либо подключить уведомления в согласованный канал. Перед публикацией дополнить сведения об операторе персональных данных и правила обработки реальными реквизитами организации.
