# Сертификат для прямого API MAX

`max-russian-trusted-root.pem` — публичный корневой сертификат Russian Trusted Root CA.

- Получен 22.10.2026 по HTTPS с официального ресурса Госуслуг: https://gu-st.ru/content/Other/doc/russian_trusted_root_ca.cer
- Инструкция официального портала: https://www.gosuslugi.ru/crt
- SHA-256 отпечаток сертификата: `D2:6D:2D:02:31:B7:C3:9F:92:CC:73:85:12:BA:54:10:35:19:E4:40:5D:68:B5:BD:70:3E:97:88:CA:8E:CF:31`.
- Срок действия: 01.03.2022–27.02.2032 (UTC).

Используется только HTTP-клиентом `App\Services\Max\MaxService` для фиксированного узла `platform-api2.max.ru`, когда задан `MAX_CA_BUNDLE=resources/certs/max-russian-trusted-root.pem`. Системное хранилище доверия не изменяется. Проверка имени узла и срока сертификата остаётся включённой, HTTP-перенаправления не выполняются.

Если сертификат требуется обновить, получить актуальный файл с официального ресурса, проверить его сведения и обновить документированный отпечаток. Не скачивать корневые сертификаты из случайных репозиториев и не заменять проверку TLS на `verify=false`.
