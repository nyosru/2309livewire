# VK Friend Manager для Firefox Developer Edition

Расширение использует текущую сессию VK в этом же профиле Firefox. Оно не читает и не передаёт сайту cookies, пароль или OAuth-токен. Доступ расширения ограничен `https://vk.php-cat.ru` и `https://vk.com`.

## Временная установка

1. Откройте `about:debugging#/runtime/this-firefox` в Firefox Developer Edition.
2. Нажмите **Загрузить временное дополнение…** и выберите `browser-extension/manifest.json`.
3. Обновите страницу `https://vk.php-cat.ru/`.
4. Отметьте друзей на текущей странице и нажмите **Удалить выбранных**. Во всплывающем подтверждении подтвердите действие.

Временное дополнение действует до перезапуска Firefox. После перезапуска загрузите его снова.

Расширение открывает отдельную вкладку VK, сверяет аккаунт с аккаунтом сайта и перед каждым удалением проверяет URL профиля. Если VK показывает проверку безопасности или интерфейс не распознан, обработка остановится. Ошибка отдельного профиля попадёт в итоговый отчёт, после чего обработка продолжится.
